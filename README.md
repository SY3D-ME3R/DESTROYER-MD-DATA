# DESTROYER-MD-DATA

Media files for **DESTROYER-MD (BOT 2)** — menu videos, images and other assets served to the bot.

## Menu video

Put the menu video in `videos/` (small, 3–5 MB, under 60 seconds for the round video-note style). Then use its raw link in the bot:

```
https://raw.githubusercontent.com/SY3D-ME3R/DESTROYER-MD-DATA/main/videos/<filename>.mp4
```

## Folders

- `videos/` — menu videos and clips for BOT 2
